# header

Shared page header surface for entity detail pages.

`Header` provides the sticky page-level surface, an optional raised entity icon,
and neutral or status-aware background variants. Feature pages provide their
own identity, supporting information, and actions as children.

## Variants

- `default` — neutral page header.
- `success`, `danger`, `warning`, `pending`, `info` — status-aware backgrounds.

## Running unit tests

Run `nx test header` to execute the unit tests via Vitest.
